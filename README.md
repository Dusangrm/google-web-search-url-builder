# Google Web search URL builder

Open `index.html` in a browser and enter a search term. The tool builds a Google Web URL locally. Open the result in a new tab or copy the shown address. Building a link does not send a request. Opening the link sends the query to Google.

The Web view focuses on links for a single query. To get back to the usual Google layout, choose **All** in Google. This tool does not change your default search engine.

Made by the team behind [Get Rid of AI Overview](https://getridofaioverview.com/google-web-filter/?utm_source=github&utm_medium=referral&utm_campaign=overview_geo_launch).
